# 🔌 USB Plug-and-Play & Teacher Setup Guide

> **Nani Typing:** Zero-Database, Zero-Maintenance Educational Architecture

---

## 🚀 Quick Start in 60 Seconds

1. **Grab any USB thumb drive.**
2. **Create a folder named:** `NaniTyping`
3. **Drop your photos inside**, naming each file after the word you want to trigger:
   * `kodi.webp` &rarr; Triggers when your child types **KODI**
   * `hen.png` &rarr; Triggers when your child types **HEN**
   * `mamma.jpg` &rarr; Triggers when your child types **MAMMA**
   * `car.webp` &rarr; Triggers when your child types **CAR**
4. **Plug the USB drive into your Android TV or tablet.**
5. **Open Nani Typing.** The app automatically detects the USB drive, indexes the photos, and is ready!

## 🌍 Instant Multilingual Learning (Zero Translation Tables)

Because the trigger is directly the filename, you can teach any language or dialect without code changes:

| Language | Example Filename | Trigger Word |
| :--- | :--- | :--- |
| **Telugu** | `kukka.jpg` | **KUKKA** (Dog) |
| **Hindi** | `kutta.jpg` | **KUTTA** (Dog) |
| **Tamil** | `naai.jpg` | **NAAI** (Dog) |
| **English** | `dog.jpg` | **DOG** |

*Matching is completely case-insensitive (`DOG`, `dog`, `Dog` all match).*

## 🏎️ Kinetic Action Words Reference

Typing these active words triggers real physical kinetic dynamics on the screen:

* `FAST`, `SPEED`, `RUN` &rarr; High-velocity linear rush ($450\text{ms}$)
* `SLOW`, `CRAWL` &rarr; Measured deliberate crawl ($3.5\text{s}$)
* `STOP`, `HALT`, `WAIT` &rarr; Screeches to an immediate halt with braking recoil
* `DOWN`, `DROP`, `FALL` &rarr; Gravitational descent down an architectural ramp
* `UP`, `CLIMB` &rarr; Uphill climb overcoming gravity
* `BOUNCE`, `HOP` &rarr; Free-fall drop with elastic spring rebound and squash-and-stretch
* `JUMP` &rarr; Parabolic leap and return to ground

## ⌨️ Physical Keyboard Controls

* **Any Key:** Speaks letter name immediately.
* **Spacebar:** Spells completed word letter-by-letter with orange highlight &rarr; speaks whole word &rarr; flashes photo or physics action.
* **Enter:** Spells and pronounces word, then moves to a new line.
* **Backspace (`DEL`):** Erases last letter and mutes any ongoing audio immediately.
* **Escape / Back:** Completely clears screen and announces *"Reset"*.
